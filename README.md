# UMLP – Master’s in Internet of Things (M2)

This repository contains the coursework, assignments, and projects completed during the Master’s in Internet of Things (IoT) program at Marie and Louis Pasteur University, UFR STGI, Montbeliard (Year 2026 - 2027).

It includes:

- A list of all subjects taught in the program

- Names of instructors for each course

- Publicly available links to course materials

- Folders with corresponding assignments and project work
